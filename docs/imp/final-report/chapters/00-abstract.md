Automated machine learning (AutoML) libraries such as FLAML search for a good model and its hyperparameters within a time budget, but the experimentation around the search is still left to the user: finding out why a model is weak, deciding what to change in the data or the settings, judging whether a change really helped and deciding when to stop. This project built AutoPilot-ML, an autonomous experimentation layer that runs this whole loop by itself on tabular data, on a laptop and fully offline, with FLAML as its search engine.

After each experiment, a Critic diagnoses weaknesses (14 kinds, such as overfitting, class imbalance or misleading high-cardinality columns) from evidence measured on 15 fixed folds of the training data. A Strategy Engine proposes one of 12 changes, and a Judge keeps a change only if a corrected resampled t-test on the same folds shows that it is better, or that it is simpler and not worse. A Resource Manager divides the time budget and decides when to stop, and an Experiment Memory records every change with its effect and cost, from which Thompson sampling learns which changes to try first on similar datasets. The system comes with a Streamlit dashboard, a command line, a local web API, a Docker image and 586 automated tests.

On data with known answers, the Critic's data-level diagnoses never raised a false alarm and the Judge accepted none of 18 harmful changes. In a benchmark of 390 runs on 6 public OpenML datasets, AutoPilot-ML made strong use of a larger budget: from 2 to 5 minutes its score rose on 5 of the 6 datasets and its average rank rose from fourth to second of five systems. At 5 minutes it matched FLAML alone within the statistical intervals while using 29% less time, outperformed AutoGluon and a LightGBM baseline with default settings on most datasets, and gave the best score of all systems on the imbalanced pc4 dataset. The result is a working, tested and fully offline system whose every decision is explained, recorded and repeatable.

**Keywords:** automated machine learning, FLAML, autonomous experimentation, corrected resampled t-test, multi-armed bandits, tabular data.

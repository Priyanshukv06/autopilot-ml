Our project lies in automated machine learning (AutoML) for tabular data, the kind of data kept in spreadsheets and databases. It brings together machine learning, statistics and software engineering.

In machine learning, the work covers model selection and hyperparameter search, and the diagnosis of common weaknesses of a model, such as overfitting, class imbalance, missing values and misleading or leaking columns, together with the changes to the data and the settings that answer them.

In statistics, it covers the fair comparison of two models with repeated cross-validation and the corrected resampled t-test, and the comparison of several systems over many datasets with the Friedman, Nemenyi and Wilcoxon tests. In decision making under uncertainty, it uses multi-armed bandits, Thompson sampling and UCB1, to learn from earlier experiments which changes to try first.

In software engineering, it is a tested and modular Python system with a web dashboard, a command line, a local web API and a Docker image, built from a written specification and run fully offline on a laptop.

Automated machine learning (AutoML) libraries such as FLAML search for a good model and its hyperparameters within a time budget, but they leave the experimentation around the search to the user: finding out why a model is weak, deciding what to change in the data or the settings, judging whether a change really helped and deciding when to stop. This project built AutoPilot-ML, an autonomous experimentation layer that runs this loop by itself on tabular data, on a laptop and fully offline, with FLAML used unchanged as its search engine.

After each Experiment, a Critic diagnoses weaknesses (14 kinds, such as overfitting, class imbalance or misleading high-cardinality columns) from evidence measured on 15 fixed folds of the training data. A Strategy_Engine proposes one of 12 changes, and a Judge keeps a change only if a corrected resampled t-test on the same folds shows that it is better, or that it is simpler and not worse. A Resource_Manager divides the time budget and decides when to stop, and an Experiment_Memory records every change with its effect and cost, from which Thompson sampling learns which changes to try first on similar datasets. The system has a Streamlit dashboard, a command line, a local web API, a Docker image and 586 automated tests.

On synthetic data with known answers, the Critic's data-level Diagnoses gave no false alarm and the Judge accepted none of 18 harmful changes. A benchmark fixed in advance then compared the system with FLAML alone, AutoGluon and LightGBM's default settings in 390 runs on 6 OpenML datasets, with 5 seeds and budgets of 120 and 300 seconds. With the same budget, one FLAML search was as good as the loop or better: at 120 seconds FLAML alone was ahead on all six datasets (median difference 0.0137), and at 300 seconds the two were level within the bootstrap intervals. The hypothesis that the loop reaches the target score sooner was contradicted, and the others were not shown. The project therefore delivers explained, recorded and repeatable experimentation decisions rather than higher scores, and its measurements show where the budget is lost.

**Keywords:** automated machine learning, FLAML, autonomous experimentation, corrected resampled t-test, multi-armed bandits, tabular data.
